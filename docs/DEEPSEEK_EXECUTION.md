## 两个终端启动

先在旧console输入退出，再在旧bringup终端Ctrl+C。当前已构建，启动：

```bash
source /opt/ros/jazzy/setup.bash
source /home/ma/lite3_ws/install/setup.bash
ros2 launch lite3_navigation bringup.launch.py ai_control:=true language_mode:=deepseek
```

等待READY后在终端2：

```bash
source /opt/ros/jazzy/setup.bash
source /home/ma/lite3_ws/install/setup.bash
ros2 run lite3_navigation ai_console
```

确认连接提示为“DeepSeek执行模式”。此模式的模型解析结果在本地校验通过后会执行，不是预览。终端会先显示易读的“理解为：依次前往……”等动作说明，再显示实际接受/拒绝、顺序进度和结果；结构化解释仍在事件的interpreted字段内。

例如逐条输入：

```text
帮我看看目前保存了哪些地点
允许机器狗开始接收导航任务吧
麻烦先带我到点1，再去点2，最后回到原点
```

点名必须已保存，所有坐标仍受原导航地图与完整轮廓检查。模型不得补造缺失坐标；如果它提示缺少参数，可以直接补充；程序会结合最近3轮、90秒内的待澄清对话理解回答。地点持久化和原点规则保持。

停车可明确输入“停止”“关闭导航”，以及“立刻停止”“马上停下”等本地紧急别名。退出console仍会请求取消队列、关闭导航并等待确认；断线超过2.5实际秒同样清理。整套系统退出在终端1按Ctrl+C。

## 多轮澄清与名称理解

上一版不传前文，会出现“保存还是导航？”→用户“保存为”→又询问整个意图的问题。现在只保留最近3轮待澄清的用户原话和模型问题，90实际秒过期。用户补充“保存为”“1”时会将这些前文一起发送；模型解释成完整动作后清空，停止、退出/断线、网络失败、超时或地点快照失效也清空，防止旧动作复活。新完整要求应优先于旧意图，不是永久聊天记忆。

“当前位置”“当前的位置”直接表示读取当前位置，无需用户另报坐标。“家/原点”为自动记录的保留目标，本版不支持把普通存点命名为家。若同一句给了“点1或家”两个选择，仍会要求选一个，但允许后续回答。

引用已有地点时，精确名称优先：没有名称“1”而有“点1”，导航/查询的“1”“一”“点一”可以指向“点1”；若真有名称“1”，就使用它。新存点不由本地别名器悄悄改名；模型需尊重明确命名，且已有同名地点仍需覆盖确认。

导航状态拒绝分别显示故障锁定、切换未完成、其他任务忙碌或总开关关闭。关闭时会明确提示先输入“开启导航”，确认成功后重发目标，不偷偷开导航、不保留被拒绝目标等待以后自动执行。

## 本地优先与API调用

以下约定表达由本地规则优先处理：停止/关闭、状态查询、帮助、列点、单点查询、明确的覆盖确认；不等待API且不产生模型请求。新增本地停车别名：马上停下、立刻停止、立即停止、紧急停止、停车、别动、快停、快停下、马上停止、立刻停下、请停下、请停止、停下来、赶紧停下。

其他输入在空闲时请求DeepSeek，包括普通导航、自由措辞查询、保存/删除地点、开启入口。每次请求发送本句话、已保存点名列表，以及未结束的短期澄清对话（最多3轮），使用账户API额度。不发送API密钥文件内容、地图图片/点云/工程文件，也不自动附带地点坐标表；你在对话里自己输入的坐标会随原话发送。密钥仅在HTTPS认证头中使用。

一次最多一个网络请求；正在解析或执行时不接受另一个模型请求，避免排队指令在用户忘记后开始执行。停止和约定的本地查询仍可用。取消本地执行资格不意味着已发出的HTTP请求/费用一定被取消；旧线程结束前新的模型请求会提示稍后重试。

确认覆盖必须由用户明确输入“确认覆盖点名”，不让模型自行代为确认。原来的同名覆盖60秒期限、缺点拒绝整组、最多12个目标及每一步成功后再推进均保留。

## 异步执行与过期结果

`LanguageWorker`是后台节点内的一条有界守护线程，不是新ROS节点。它只请求HTTP并返回数据，不调用ROS、地点写入或控制接口。结果由ROS线程取出，重新经过JSON白名单检查，再调用原command处理。

请求绑定会话、请求编号、停止代际及地点快照。停止/退出/断线会使正在解析的请求失去执行资格；迟到结果不执行。解析期间地点记录改变会要求重说；超过30实际秒未完成也拒绝迟到结果。网络连接/读取操作超时为25秒，30秒是本地执行资格期限，不保证服务器已终止生成。

模型结果为clarify/unsupported时只显示提示；认证、额度、网络失败、空内容、截断、未知字段等不进入执行，不自动退回规则猜动作，不自动重试。未知异常仅显示通用信息，不输出认证头、HTTP正文或密钥。

明确的本地停止指令是优先控制入口；不要把含糊的“算了吧”“先这样”当作已确认停车。现有项目的停止/开关方式继续保留。JSON协议检查不保证模型语义永远正确；首次真实测试先用近距离空闲目标。

## 密钥与备用模式

沿用仓库外`/home/ma/.config/lite3_navigation/deepseek.json`，要求本人所有、普通文件、权限600，禁止符号链接。密钥不放ROS参数、启动命令或Git。独立预览工具仍然只解析、不控制机器人。

恢复原固定句式入口，不需要密钥或网络：

```bash
ros2 launch lite3_navigation bringup.launch.py ai_control:=true language_mode:=rules
```

模式在启动读取，切换需退出旧系统并重新启动。省略language_mode仍为rules。通过console的连接提示核对，避免把独立预览与正式控制混淆。
