**① 先在两个终端分别按 `Ctrl+C`，停止策略和仿真。**

**② 打开 [lite3_test_policy_runner_onnx.cpp](/home/ma/Lite3_rl_deploy/run_policy/lite3_test_policy_runner_onnx.cpp)**

找到：

```cpp
void Lite3TestPolicyRunnerONNX::OnEnter() {
    run_cnt_ = 0;
    current_obs_.setZero(obs_dim_);
```

在 `current_obs_` 这一行下面增加：

```cpp
    last_action.setZero(act_dim_);
```

意义：**每次进入 RL，都把上一次的 12 个关节动作清零，不继续使用旧的异常数据。**

**③ 打开 [rl_control_state_onnx.hpp](/home/ma/Lite3_rl_deploy/state_machine/rl_control_state_onnx.hpp)**

找到这两行：

```cpp
run_policy_thread_ = std::thread(std::bind(&RLControlStateONNX::PolicyRunner, this));
policy_ptr_->OnEnter();
```

把顺序交换为：

```cpp
policy_ptr_->OnEnter();
run_policy_thread_ = std::thread(std::bind(&RLControlStateONNX::PolicyRunner, this));
```

意义：**先初始化策略数据，再启动计算动作的线程。** 避免程序还没准备好就开始计算。

**④ 保存两个文件，然后在终端 2 编译：**

```bash
cmake --build /home/ma/Lite3_rl_deploy/build -j 4
```

先做到这里。编译成功后，我们再启动验证：只测试 `z → c` 的原地站立，确认目标位置和力矩不再出现 `nan`。
