# 遮挡、障碍记忆与清除确认（2026-10-20）

## 这次在修什么

用户发现新增箱子的边沿随机器狗移动/转弯时出现又消失，全局地图可能因此产生捷径，再发现箱子后又绕行。我们需要同时做到两件事：看不见时不要贸然删除；确实看见旧位置空了时允许删除，避免箱子移走后“绕空气”。

这次没有增加ROS2节点。改动位于`lite3_perception`包的`FlatGroundVoxelLayer`，它是全局与局部costmap内部的插件。雷达、点云消息、RL运动控制、任务接口和原有路线优化流程保持原结构。

## 已确认的现象及判断边界

独立场景使用真实Gazebo GPU雷达、原生PosePublisher提供的扫描位姿TF、现有感知节点及Nav2全局/局部地图，摆放三个0.6米箱子，关闭预测层以隔离实测体素行为。

旧版在25个移动视角中，最初记录的24个箱面边界格最低剩17个，之后又恢复24。变化集中在箱面附近的5厘米栅格边界。同一物理表面在不同角度下可能命中相邻体素，擦边的空闲射线不能证明整个旧体素都空了。

这证明了一种可复现的边界占据波动，不证明原生Nav2完全不考虑遮挡，更不能证明用户现场全部波动只有这一种原因。原生射线本来就在命中物体处终止；扫描时刻TF、预测层和其他来源仍需按具体现场证据判断。

## 现在如何标记与清除

1. **标记仍沿用原流程。** `/lite3/perception/obstacles`中的已确认回波标记相应高度体素，再投影到二维代价地图。不会根据Gazebo箱子真值补齐隐藏轮廓。
2. **清除先走原生射线。** `/lite3/perception/clearing`保留真实传感器原点、有效命中和已验证的无命中射线。只有原生三维射线实际清到旧占据位时，才进入新增确认。
3. **检查同一帧的近处回波。** 对真实非地面、非无命中端点建立三维角度—最近距离表。把旧体素的空间大小和扫描间隔计入角度邻域；若近处实测回波使该位置存在遮挡/表面边界不确定性，恢复这个旧高度位，并清零其空闲计数。
4. **确认确实空闲。** 没有上述冲突、且射线清到该高度时，累计不同时间戳的清除证据。默认3次；同一消息被地图反复使用只算一次。中断、时间倒退、重新初始化会重置相应计数。局部滚动窗口平移时，计数随同一世界位置的体素平移，不移到别处。
5. **只删除得到证据的高度位。** 不清整列、不设置障碍到期时间、不删除静态地图，不用“等待几秒”代替几何证据。其他高度还有实测占据时，二维格仍然可以是障碍。

例如：先扫描后方箱子，再有近箱挡住它，后箱旧记录应保留；即使后箱此时实际被移走，只要近箱还挡着，也无法从雷达确定后面变空。近箱移开后，射线能穿过后箱原位置，连续确认后才清除。

## 参数与代价

四份导航配置的`voxel_layer`均显式设置：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| clearing_confirmation_frames | 3 | 清除需要的不同扫描时间戳数；允许1～10 |
| clearing_occlusion_angle | 0.03 rad | 在体素角度大小外增加的保守邻域，约1.72°；允许0～0.1 |

参数在插件初始化读取，修改后需要构建并重启；不是终端动态调参接口。确认会增加少量延迟，具体取决于有效扫描、地图更新、仿真速度和可见性，不承诺固定几百毫秒。

角度邻域有意保守：靠近另一个物体或表面擦边时，可能继续保留旧体素，需要更明确的新视角。360度水平扫描也不代表连续覆盖所有高度。例如相距3度的两条垂直扫描线，在远处可能一条从旧体素上面经过、一条从下面经过；二维位置看起来可见仍不能证明这个高度空闲。这种情况下不会盲清。

## 你在完整系统里怎么验证

本轮已构建。旧系统若仍打开，先在bringup终端按Ctrl+C退出，然后按原启动方式：

```bash
source /opt/ros/jazzy/setup.bash
source /home/ma/lite3_ws/install/setup.bash
ros2 launch lite3_navigation bringup.launch.py
```

等待READY，在另一个终端source同样两个环境，开启入口：

```bash
ros2 service call /lite3/set_navigation_enabled std_srvs/srv/SetBool '{data: true}'
```

用原Gazebo面板放箱、选导航目标。先保持三个箱子不动，让机器狗从不同方向经过：重点看全局costmap中先前记录的边沿是否无故消失，是否仍因暂时捷径反复换路。

再分开验证：先扫描一个箱子；用另一个箱子挡住它，移走后箱，旧记录应暂时保留；移走前箱，让机器狗在宽敞安全处换角度/距离扫描，旧记录应在有效空闲证据确认后清除。不要为了测试把机器狗放进障碍或窄缝。

判断时区分红色点云与costmap：红点只显示当前可见回波；历史记录在代价地图中，可以继续存在。预测层的渐变区域也不是实测箱体，必要时按层排查。
