## 数据流程

Gazebo GPU雷达（720方向×31层，垂直-60°～+30°，10Hz仿真时间）
→ 同一ros_gz_bridge → `/lite3/lidar/points`（PointCloud2，lidar_link）
→ 扫描时刻TF补偿 → 平地/自身/高度筛选 → Nav2体素层 → 二维costmap。

雷达固定在TORSO前方0.30米、上方0.15米，传感器与TF位姿一致。
前移用于降低前方低障碍被机身遮挡的概率，不代表消除了遮挡/盲区。
无附加质量/碰撞几何，原关节和RL动力学参数保持不变。

| 输出 | 消息/坐标 | 用途 |
|---|---|---|
| /lite3/perception/obstacles | PointCloud2，lidar_link | 已过滤的障碍回波，Nav2只用于标记 |
| /lite3/perception/clearing | PointCloud2，lidar_link | 真实有效回波端点及已验证Gazebo无命中射线量程端点，Nav2只用于三维射线清除 |
| /lite3/perception/ground | PointCloud2，lidar_link | 地面分类调试显示，不能作为障碍标记源 |
| /lite3/perception/forecast | PointCloud2，odom | 连续雷达帧估计的未来占据，独立ForecastLayer使用，不能当作实测回波或清除源 |
| /scan | LaserScan，base_footprint | 多高度障碍的水平二维投影；不再是原单层物理扫描 |
| /lite3/perception/status | String，JSON | 分类计数/模式/高度上限/运动估计，约每2秒输出 |

所有点云/投影保留原仿真时间戳，使用BEST_EFFORT、depth=1。
处理最新帧，非阻塞等待扫描时刻的TF，过期0.3秒丢弃而不重发旧数据。
Nav2以真实lidar_link为射线原点，不拿投影scan的虚拟地面原点做清除。
有效Gazebo无命中射线只在配置量程内提供空闲证据；无效数据、遮挡和未扫描方向不推断为空闲。

## 平地规则

配置在 `config/flat_ground.yaml`：当前concrete_floor顶面是odom z=0.005米。
先将点转换到odom，过滤地面容差0.02米；障碍候选高度为(0.025,0.65]米。
0.65米是正常站姿含雷达的固定保守上限，不是随姿态动态计算的最高点。
机器狗自身按TORSO坐标的包围盒掩蔽，近身区域也因此存在不可观察范围。
下扫地面仍保留在clearing点云，可用来清除原低障碍位置的体素。

全局/局部costmap的static_layer继续保护原地图障碍；新增voxel_layer后再inflation。
此处使用FlatGroundVoxelLayer（继承Nav2 VoxelLayer）：只对已知地面回波补偿基类
两格端点退让，基类射线实际结束在测得的地面附近，普通障碍回波沿用原保守算法。
原始点云和标记观察深拷贝隔离，不把地面后方或遮挡区域清空；仅适用当前Jazzy平地配置。
体素高度0～0.70米，0.10米/层、7层；标记高度与过滤器一致。
两种源的expected_update_rate=0.5是秒，持续断流会使costmap不再新鲜。
过滤节点退出触发整套launch关闭；启动就绪阶段等待新鲜感知输出。

仅用于平地。厘米级低障碍可能落入地面容差，有限扫描线可能漏检小物体。
起伏/斜坡需要当地地面识别与可通行判断；坑洞、跌倒恢复和全覆盖安全未实现。
2026-10-17增加紧凑物体短期运动估计，复用本节点；真实观测/清除不变。
详见[持续避让说明](../../docs/CONTINUOUS_AVOIDANCE.md)，其中记录参数、预测层失效清除及局限。
任务恢复由mission_manager负责，不由本感知节点发送速度、解锁或重新规划请求。
SLAM尚未接入；/scan是多高度近邻投影，用作SLAM前需另行验证建图/定位几何。

## 2026-10-18：货架旁误报无路与额外障碍标记（当前修复）

本次以用户现场实时地图、位姿和日志为依据，不继续缩小机器人轮廓。

- 用户停在货架旁时，实际0.84×0.40米矩形没有碰到致命格，但原diff运动集中所有可扩展动作均被挡。
  原生Lattice会将这种“没有可执行下一步”的情况报成205（起点占用），不能由205反推身体已碰撞。
  同一冻结地图，原diff返回205；omni运动集可以输出156点路线。
- 默认MPPI改为Omni，允许横移，横向上限0.30m/s、采样标准差0.25m/s；Lattice同时选安装包的5cm omni运动集。
  后退、完整矩形、碰撞检查和原速度上限保留。controller:=rpp仍选diff运动集，原NavFn回退保留。
  原RL策略文件不变；真实RL左右横移及斜向移动单独测试已通过。
- 平地模式增加有界地面平面拟合，避免仅凭固定世界高度误标轻微倾斜的地面回波。
  至少80个分散地面样本、X/Y跨度各2米、坡度≤0.035、雷达脚下偏差≤2cm；不满足时丢弃整帧标记/清除，
  不推断未知区域安全。仍然只用于平地，不能据此宣称支持斜坡/台阶。
- 障碍标记增加8cm三维网格邻域至少3个回波支持、相邻两帧确认（XY邻格允许移动）。
  只过滤障碍标记，真实清除射线不因此删改；约增加一帧（10Hz时约0.1仿真秒）确认等待。
  小而细、远距离稀疏物体可能漏检，不能把此过滤当作安全保证。
- clearing PointCloud2新增FLOAT32字段ground，明确标识被判定为地面的实测端点。
  FlatGroundVoxelLayer读取此字段补偿原两格端点退让，不再依赖补偿前世界z是否恰好接近0.005。
  xyz、时间戳和真实射线原点不变；没有整列清空、按静态地图屏蔽新障碍或超时盲目删除实测障碍。
- /lite3/perception/status新增raw_obstacles（确认前计数）和ground_plane（z=a*x+b*y+c系数/null）。
  mission_manager对位姿检查失败新增时间年龄/TF查询警告，方便区分感知受阻和定位链路故障。

验证结果及保留的失败见本次证据README；原整体架构、SLAM计划及节点分工不改。
本轮修改尚未提交/推送；2026-10-17同步清单是历史快照。

### 同日后续：清除链路与输出检查

现场及空地测试录得部分远距地面回波落在约1.5～3.5cm高度，
仅两帧确认仍会留下少量候选点。新增ground_range_uncertainty=0.003：每米额外3mm低回波不确定带。
例如1米处需高于拟合地面约2.3cm，8米处约4.4cm；不会承诺检测所有厘米级小物体。
这类不确定点不是ground标记，普通真实清除射线端点保留，不能据此清掉悬空物体。
最大量程端点不标障碍（distance≥range_max-1mm），仍保留清除端点。
竖向体素改为10cm×7层，仍覆盖0～0.70米；XY仍5cm、实际障碍高度上限仍0.65米。
这减少稀疏竖直扫描在细体素中留下的零散旧痕迹，未使用盲目过期/整列清除。

AvoidanceController新增实际速度输出的1秒前视完整轮廓检查，50ms步长，
同时检查中心危险格、边界未知/致命格；拒绝后沿原Nav2失败/任务暂停和有限恢复处理。
MPPI候选评分之外，最终加权平滑指令也要通过检查；预测仍有时序/跟踪误差，不能保证任意动态场景安全。

试验过Lite3ResponseCritic（减少微小无效速度偏好），但移动箱子出现接触、另一次偏离路线后103失败。
该试验保留源码/插件与失败证据，**不在默认critics列表中、enabled=false**，不得按已经修复低速执行宣传。
额外执行前检查保留；没有改RL策略，也没有重新启用原VelocityDeadbandCritic。
